## Kết nối cơ sở dữ liệu MySQL từ Python

Trong Python 3, chúng ta có thể sử dụng thư viện bên thứ ba `mysqlclient` hoặc `pymysql` để kết nối vào cơ sở dữ liệu MySQL và thực hiện các thao tác lưu trữ dữ liệu bền vững. Cách sử dụng của cả hai hoàn toàn giống nhau, chỉ khác nhau ở tên module được import. Chúng tôi khuyên bạn nên sử dụng thư viện thuần Python `pymysql`, vì nó dễ cài đặt thành công hơn. Dưới đây, chúng ta vẫn tiếp tục lấy cơ sở dữ liệu có tên là `hrs` đã tạo trước đó làm ví dụ để minh họa cách thao tác với cơ sở dữ liệu MySQL thông qua chương trình Python nhằm thực hiện lưu trữ dữ liệu bền vững.

### Kết nối MySQL

Trước tiên, chúng ta có thể cài đặt `pymysql` trong dòng lệnh hoặc terminal của PyCharm bằng câu lệnh dưới đây. Nếu cần kết nối với MySQL 8, bạn còn cần cài đặt thêm thư viện bên thứ ba tên là `cryptography` để hỗ trợ phương thức xác thực mật khẩu của MySQL 8:

```Shell
pip install pymysql cryptography
```

Các bước thao tác với MySQL bằng `pymysql` như sau:

1. Tạo kết nối. Sau khi máy chủ MySQL khởi động, nó cung cấp dịch vụ mạng dựa trên TCP (Transmission Control Protocol - Giao thức điều khiển truyền vận). Chúng ta có thể kết nối tới máy chủ MySQL thông qua hàm `connect` của module `pymysql`. Khi gọi hàm `connect`, cần chỉ định các tham số như máy chủ (`host`), cổng (`port`), tên người dùng (`user`), mật khẩu (`password`), cơ sở dữ liệu (`database`), bộ ký tự (`charset`), v.v.; hàm này sẽ trả về một đối tượng `Connection`.
2. Lấy con trỏ (Cursor). Sau khi kết nối thành công tới máy chủ MySQL, bước tiếp theo là gửi câu lệnh SQL tới máy chủ cơ sở dữ liệu; MySQL sẽ thực thi câu lệnh SQL nhận được và trả kết quả thực thi về qua mạng. Để thực hiện thao tác này, trước tiên cần lấy đối tượng con trỏ (`Cursor`) thông qua phương thức `cursor` của đối tượng kết nối.
3. Gửi câu lệnh SQL. Thông qua phương thức `execute` của đối tượng con trỏ, chúng ta có thể gửi câu lệnh SQL tới cơ sở dữ liệu.
4. Nếu thực thi thao tác `insert`, `delete` hoặc `update`, cần commit hoặc rollback giao dịch tùy theo tình hình thực tế. Bởi vì khi tạo kết nối, môi trường giao dịch được bật theo mặc định; sau khi hoàn thành thao tác, cần sử dụng phương thức `commit` hoặc `rollback` của đối tượng kết nối để thực hiện commit hoặc rollback giao dịch, phương thức `rollback` thường được đặt trong khối mã bắt ngoại lệ `except`. Nếu thực thi thao tác `select`, cần lấy kết quả truy vấn thông qua đối tượng con trỏ; có ba phương thức tương ứng là: `fetchone`, `fetchmany` và `fetchall`. Trong đó phương thức `fetchone` sẽ lấy ra một bản ghi và trả về dưới dạng tuple hoặc từ điển (dict); phương thức `fetchmany` và `fetchall` sẽ lấy ra nhiều bản ghi, trả về dưới dạng tuple lồng nhau hoặc danh sách chứa các từ điển (list of dicts).
5. Đóng kết nối. Sau khi hoàn thành thao tác lưu trữ bền vững, xin đừng quên đóng kết nối để giải phóng tài nguyên bên ngoài. Chúng ta thường sử dụng phương thức `close` của đối tượng kết nối trong khối mã `finally` để đóng kết nối.

### Thực hành mã nguồn

Dưới đây, chúng ta sẽ thực hành viết mã để minh họa năm bước đã nêu ở trên.

#### Chèn dữ liệu

```Python
import pymysql

no = int(input('Mã phòng ban: '))
name = input('Tên phòng ban: ')
location = input('Địa điểm phòng ban: ')

# 1. Tạo kết nối (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Lấy đối tượng con trỏ (Cursor)
    with conn.cursor() as cursor:
        # 3. Gửi câu lệnh SQL tới máy chủ cơ sở dữ liệu qua đối tượng con trỏ
        affected_rows = cursor.execute(
            'insert into `tb_dept` values (%s, %s, %s)',
            (no, name, location)
        )
        if affected_rows == 1:
            print('Thêm phòng ban mới thành công!!!')
    # 4. Commit giao dịch (transaction)
    conn.commit()
except pymysql.MySQLError as err:
    # 4. Rollback giao dịch
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Đóng kết nối giải phóng tài nguyên
    conn.close()
```

> **Giải thích**: Địa chỉ `127.0.0.1` ở trên được gọi là địa chỉ loopback (vòng lặp), nó đại diện cho chính máy tính cục bộ. Người dùng `guest` ở dưới là người dùng tôi đã tạo trước, người dùng này có các quyền `insert`, `delete`, `update` và `select` trên cơ sở dữ liệu `hrs`. Chúng tôi không khuyên các bạn sử dụng trực tiếp tài khoản quản trị viên tối cao `root` để truy cập cơ sở dữ liệu trong các dự án, làm như vậy là vô cùng nguy hiểm. Chúng ta có thể sử dụng các lệnh dưới đây để tạo người dùng có tên là `guest` và cấp quyền cho người dùng đó:
>
> ```SQL
> create user 'guest'@'%' identified by 'Guest.618';
> grant insert, delete, update, select on `hrs`.* to 'guest'@'%';
> ```

Nếu muốn chèn một lượng lớn dữ liệu, bạn nên sử dụng phương thức `executemany` của đối tượng con trỏ để thực hiện xử lý hàng loạt (một thao tác `insert` đi kèm nhiều nhóm dữ liệu). Các bạn có thể thử chèn 10.000 bản ghi vào một bảng, sau đó so sánh sự khác biệt giữa việc chèn từng dòng không dùng batch processing và việc sử dụng batch processing. Tham số thứ nhất của phương thức `executemany` vẫn là câu lệnh SQL, tham số thứ hai có thể là một danh sách (list) hoặc tuple chứa nhiều nhóm dữ liệu.

#### Xóa dữ liệu

```Python
import pymysql

no = int(input('Mã phòng ban: '))

# 1. Tạo kết nối (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4',
                       autocommit=True)
try:
    # 2. Lấy đối tượng con trỏ (Cursor)
    with conn.cursor() as cursor:
        # 3. Gửi câu lệnh SQL tới máy chủ cơ sở dữ liệu qua đối tượng con trỏ
        affected_rows = cursor.execute(
            'delete from `tb_dept` where `dno`=%s',
            (no, )
        )
        if affected_rows == 1:
            print('Xóa phòng ban thành công!!!')
finally:
    # 5. Đóng kết nối giải phóng tài nguyên
    conn.close()
```

> **Giải thích**: Nếu không muốn phải commit hoặc rollback giao dịch thủ công sau mỗi thao tác SQL, bạn có thể thêm một tham số tên là `autocommit` vào hàm `connect` và đặt giá trị của nó thành `True`, biểu thị tự động commit sau mỗi lần thực thi SQL thành công. Tuy nhiên chúng tôi khuyên bạn nên commit hoặc rollback thủ công, như vậy có thể chủ động cấu trúc môi trường giao dịch theo đúng nhu cầu nghiệp vụ thực tế. Nếu không muốn bắt ngoại lệ và xử lý nó, bạn có thể đặt khối `finally` trực tiếp sau khối `try`; việc bỏ qua `except` đồng nghĩa với việc khi phát sinh ngoại lệ, mã lệnh sẽ lập tức dừng lại và hiển thị traceback ngoại lệ trên terminal.

#### Cập nhật dữ liệu

```Python
import pymysql
```

#### Truy vấn dữ liệu

1. Truy vấn dữ liệu từ bảng phòng ban:

```Python
import pymysql

# 1. Tạo kết nối (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Lấy đối tượng con trỏ (Cursor)
    with conn.cursor() as cursor:
        # 3. Gửi câu lệnh SQL tới máy chủ cơ sở dữ liệu qua đối tượng con trỏ
        cursor.execute('select `dno`, `dname`, `dloc` from `tb_dept`')
        # 4. Lấy dữ liệu qua đối tượng con trỏ
        row = cursor.fetchone()
        while row:
            print(row)
            row = cursor.fetchone()
except pymysql.MySQLError as err:
    print(type(err), err)
finally:
    # 5. Đóng kết nối giải phóng tài nguyên
    conn.close()
```

> **Giải thích**: Trong đoạn mã trên, chúng ta xây dựng một vòng lặp `while` để thực hiện thao tác lấy kết quả truy vấn từng dòng một. Cách làm này đặc biệt phù hợp với những trường hợp kết quả truy vấn có rất nhiều dòng. Bởi vì nếu dùng `fetchall` để lấy toàn bộ bản ghi cùng lúc vào một tuple lồng nhau, nó sẽ gây tiêu tốn bộ nhớ rất lớn, điều này trong nhiều tình huống không phải là một giải pháp tốt. Nếu không muốn dùng vòng lặp `while`, bạn cũng có thể cân nhắc dùng hàm `iter` để tạo một iterator nhằm lấy dữ liệu từng dòng, độc giả quan tâm có thể tự mình tìm hiểu thêm.

2. Truy vấn phân trang dữ liệu từ bảng nhân viên:

```Python
import pymysql

page = int(input('Số trang: '))
size = int(input('Số dòng mỗi trang: '))

# 1. Tạo kết nối (Connection)
con = pymysql.connect(host='127.0.0.1', port=3306,
                      user='guest', password='Guest.618',
                      database='hrs', charset='utf8')
try:
    # 2. Lấy đối tượng con trỏ (Cursor)
    with con.cursor(pymysql.cursors.DictCursor) as cursor:
        # 3. Gửi câu lệnh SQL tới máy chủ cơ sở dữ liệu qua đối tượng con trỏ
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal` from `tb_emp` order by `sal` desc limit %s,%s',
            ((page - 1) * size, size)
        )
        # 4. Lấy dữ liệu qua đối tượng con trỏ
        for emp_dict in cursor.fetchall():
            print(emp_dict)
finally:
    # 5. Đóng kết nối giải phóng tài nguyên
    con.close()
```

### Phân tích ca tình huống

Dưới đây, chúng tôi sẽ hướng dẫn một ví dụ xuất dữ liệu từ bảng cơ sở dữ liệu ra tệp Excel. Trước tiên chúng ta cần cài đặt thư viện bên thứ ba `openpyxl`, câu lệnh như sau:

```Bash
pip install openpyxl
```

Tiếp theo, chúng ta sử dụng đoạn mã dưới đây để xuất mã số, họ tên, chức danh, lương tháng, phụ cấp và tên phòng ban của tất cả nhân viên trong cơ sở dữ liệu `hrs` ra một tệp Excel:

```Python
import openpyxl
import pymysql

# Tạo đối tượng sổ làm việc (workbook)
workbook = openpyxl.Workbook()
# Lấy trang tính (worksheet) mặc định đang hoạt động
sheet = workbook.active
# Đổi tiêu đề cho trang tính
sheet.title = 'Thông tin cơ bản của nhân viên'
# Thêm hàng tiêu đề cho trang tính
sheet.append(('Mã NV', 'Họ tên', 'Chức danh', 'Lương tháng', 'Phụ cấp', 'Phòng ban'))
# Tạo kết nối (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # Lấy đối tượng con trỏ (Cursor)
    with conn.cursor() as cursor:
        # Thực thi câu lệnh SQL qua đối tượng con trỏ
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal`, coalesce(`comm`, 0), `dname` '
            'from `tb_emp` natural join `tb_dept`'
        )
        # Lấy dữ liệu qua con trỏ
        row = cursor.fetchone()
        while row:
            # Ghi dữ liệu từng dòng vào trang tính
            sheet.append(row)
            row = cursor.fetchone()
    # Lưu sổ làm việc
    workbook.save('hrs.xlsx')
except pymysql.MySQLError as err:
    print(err)
finally:
    # Đóng kết nối giải phóng tài nguyên
    conn.close()
```

Các bạn có thể tham khảo ví dụ trên và thử làm ngược lại: nhập dữ liệu từ tệp Excel vào bảng chỉ định trong cơ sở dữ liệu chỉ định xem có thành công hay không.
