## Đọc ghi file Excel với Python - Phần 1

### Giới thiệu về Excel

Excel là phần mềm bảng tính do Microsoft phát triển dành cho các hệ điều hành Windows và macOS. Nhờ giao diện trực quan, tính năng tính toán xuất sắc và các công cụ biểu đồ mạnh mẽ, kết hợp với chiến lược tiếp thị thành công, Excel luôn là phần mềm xử lý dữ liệu trên máy tính cá nhân phổ biến nhất. Đương nhiên, Excel cũng có nhiều đối thủ cạnh tranh như Google Sheets, LibreOffice Calc, Numbers,... Những sản phẩm này về cơ bản cũng tương thích với Excel, ít nhất là có thể đọc ghi các phiên bản tệp Excel tương đối mới, nhưng đây không phải là trọng tâm thảo luận của chúng ta. Nắm vững kỹ năng dùng chương trình Python để thao tác với tệp Excel sẽ giúp công việc tự động hóa văn phòng hàng ngày trở nên nhẹ nhàng và thú vị hơn rất nhiều; hơn nữa trong nhiều dự án thương mại, việc nhập (import) và xuất (export) tệp Excel là tính năng cực kỳ phổ biến.

Để thao tác với Excel, Python cần sự hỗ trợ của các thư viện bên thứ ba. Nếu muốn tương thích với các phiên bản trước Excel 2007 (tức là tệp Excel định dạng `.xls`), bạn có thể sử dụng hai thư viện `xlrd` và `xlwt` - thư viện trước dùng để đọc tệp Excel, thư viện sau dùng để ghi tệp Excel. Nếu sử dụng phiên bản Excel mới hơn (tức là tệp Excel định dạng `.xlsx`), bạn có thể sử dụng thư viện `openpyxl`. Thư viện này không chỉ thao tác được với Excel mà còn có thể thao tác với các tệp bảng tính khác dựa trên Office Open XML.

Trong chương này, trước tiên chúng ta sẽ tìm hiểu cách thao tác với tệp Excel dựa trên `xlwt` và `xlrd`. Các bạn có thể sử dụng lệnh dưới đây để cài đặt hai thư viện bên thứ ba này cùng với module công cụ phối hợp `xlutils`:

```Bash
pip install xlwt xlrd xlutils
```

### Đọc file Excel

Ví dụ trong thư mục hiện tại có một tệp Excel tên là "阿里巴巴2020年股票数据.xls" (Dữ liệu cổ phiếu Alibaba năm 2020), nếu muốn đọc và hiển thị nội dung của tệp này, bạn có thể thực hiện thông qua đoạn code dưới đây:

```python
import xlrd

# Sử dụng hàm open_workbook của module xlrd để mở tệp Excel chỉ định và nhận đối tượng Book (workbook)
wb = xlrd.open_workbook('阿里巴巴2020年股票数据.xls')
# Thông qua phương thức sheet_names của đối tượng Book để lấy tất cả tên của các sheet
sheetnames = wb.sheet_names()
print(sheetnames)
# Lấy đối tượng Sheet (worksheet) thông qua tên sheet chỉ định
sheet = wb.sheet_by_name(sheetnames[0])
# Lấy số hàng và số cột của sheet thông qua thuộc tính nrows và ncols của đối tượng Sheet
print(sheet.nrows, sheet.ncols)
for row in range(sheet.nrows):
    for col in range(sheet.ncols):
        # Lấy đối tượng Cell (ô) chỉ định thông qua phương thức cell của đối tượng Sheet
        # Lấy giá trị trong ô thông qua thuộc tính value của đối tượng Cell
        value = sheet.cell(row, col).value
        # Định dạng dữ liệu cho các hàng khác ngoài hàng tiêu đề đầu tiên
        if row > 0:
            # Cột 1 có kiểu xldate trước tiên đổi sang tuple rồi định dạng theo kiểu "năm-tháng-ngày"
            if col == 0:
                # Tham số thứ hai của hàm xldate_as_tuple chỉ nhận hai giá trị 0 và 1
                # Trong đó 0 đại diện cho ngày lấy mốc 1900-01-01, 1 đại diện cho mốc 1904-01-01
                value = xlrd.xldate_as_tuple(value, 0)
                value = f'{value[0]}年{value[1]:>02d}月{value[2]:>02d}日'
            # Các cột khác có kiểu number được xử lý thành số thực giữ lại hai chữ số thập phân
            else:
                value = f'{value:.2f}'
        print(value, end='\t')
    print()
# Lấy kiểu dữ liệu của ô cuối cùng
# 0 - Trống (empty), 1 - Chuỗi (string), 2 - Số (number), 3 - Ngày (date), 4 - Boolean, 5 - Lỗi (error)
last_cell_type = sheet.cell_type(sheet.nrows - 1, sheet.ncols - 1)
print(last_cell_type)
# Lấy các giá trị của hàng đầu tiên (dưới dạng danh sách)
print(sheet.row_values(0))
# Lấy dữ liệu trong phạm vi cột chỉ định của một hàng chỉ định (dưới dạng danh sách)
# Tham số thứ nhất là chỉ mục hàng, tham số thứ hai và thứ ba là chỉ mục bắt đầu (gồm) và kết thúc (không gồm) của cột
print(sheet.row_slice(3, 0, 5))
```

> **Gợi ý**: Tệp Excel "阿里巴巴2020年股票数据.xls" sử dụng trong đoạn code trên có thể tải về từ liên kết Baidu Netdisk sau: Liên kết: https://pan.baidu.com/s/1rQujl5RQn9R7PadB2Z5g_g Mã trích xuất: `e7b4`.

Tin rằng qua đoạn code trên, các bạn đã hiểu cách đọc một tệp Excel. Nếu muốn biết thêm kiến thức về module `xlrd`, bạn có thể đọc [tài liệu chính thức](https://xlrd.readthedocs.io/en/latest/) của nó.

### Ghi file Excel

Để ghi tệp Excel, bạn có thể tạo đối tượng workbook thông qua lớp `Workbook` của module `xlwt`, thêm worksheet thông qua phương thức `add_sheet` của đối tượng workbook, ghi dữ liệu vào ô chỉ định thông qua phương thức `write` của đối tượng worksheet, và cuối cùng lưu workbook vào tệp chỉ định hoặc vào bộ nhớ thông qua phương thức `save` của đối tượng workbook. Đoạn code dưới đây thực hiện thao tác ghi điểm thi 3 môn của 5 học sinh vào tệp Excel:

```python
import random

import xlwt

student_names = ['关羽', '张飞', '赵云', '马超', '黄忠']  # Quan Vũ, Trương Phi, Triệu Vân, Mã Siêu, Hoàng Trung
scores = [[random.randrange(50, 101) for _ in range(3)] for _ in range(5)]
# Tạo đối tượng workbook (Workbook)
wb = xlwt.Workbook()
# Tạo đối tượng worksheet (Worksheet)
sheet = wb.add_sheet('一年级二班')  # Lớp 1-2
# Thêm dữ liệu tiêu đề bảng
titles = ('姓名', '语文', '数学', '英语')  # Họ tên, Ngữ văn, Toán, Tiếng Anh
for index, title in enumerate(titles):
    sheet.write(0, index, title)
# Ghi tên học sinh và điểm thi vào các ô
for row in range(len(scores)):
    sheet.write(row + 1, 0, student_names[row])
    for col in range(len(scores[row])):
        sheet.write(row + 1, col + 1, scores[row][col])
# Lưu workbook Excel
wb.save('考试成绩表.xls')
```

### Điều chỉnh định dạng ô tính

Khi ghi tệp Excel, chúng ta còn có thể thiết lập định dạng (style) cho ô tính, chủ yếu bao gồm phông chữ (Font), căn lề (Alignment), viền ô (Border) và màu nền (Background). `xlwt` đều đóng gói các lớp tương ứng để hỗ trợ những thiết lập này. Để định dạng ô tính, trước tiên cần tạo một đối tượng `XFStyle`, sau đó thiết lập phông chữ, căn lề, viền,... thông qua các thuộc tính của đối tượng này. Ví dụ trong trường hợp trên, nếu muốn đổi màu nền của các ô tiêu đề sang màu vàng, bạn có thể thao tác như sau:

```python
header_style = xlwt.XFStyle()
pattern = xlwt.Pattern()
pattern.pattern = xlwt.Pattern.SOLID_PATTERN
# 0 - Đen, 1 - Trắng, 2 - Đỏ, 3 - Xanh lục, 4 - Xanh lam, 5 - Vàng, 6 - Hồng, 7 - Xanh lơ
pattern.pattern_fore_colour = 5
header_style.pattern = pattern
titles = ('姓名', '语文', '数学', '英语')
for index, title in enumerate(titles):
    sheet.write(0, index, title, header_style)
```

Nếu muốn thiết lập phông chữ chỉ định cho tiêu đề, bạn có thể sử dụng lớp `Font` và thêm đoạn code như sau:

```python
font = xlwt.Font()
# Tên phông chữ
font.name = '华文楷体'
# Cỡ chữ (20 là đơn vị cơ sở, 18 tương ứng với 18px)
font.height = 20 * 18
# Có in đậm không
font.bold = True
# Có in nghiêng không
font.italic = False
# Màu chữ
font.colour_index = 1
header_style.font = font
```

> **Lưu ý**: Tên phông chữ (`font.name`) được chỉ định trong đoạn code trên phải là phông chữ có sẵn trên hệ thống của bạn, ví dụ trên máy tính tác giả có phông chữ tên là "华文楷体" (Hoa Văn Giai Thể).

Nếu muốn căn giữa tiêu đề theo chiều dọc, bạn có thể thiết lập bằng đoạn code sau:

```python
align = xlwt.Alignment()
# Căn lề theo chiều dọc
align.vert = xlwt.Alignment.VERT_CENTER
# Căn lề theo chiều ngang
align.horz = xlwt.Alignment.HORZ_CENTER
header_style.alignment = align
```

Nếu muốn thêm đường viền nét đứt màu vàng cho tiêu đề, bạn có thể sử dụng đoạn code sau:

```python
borders = xlwt.Borders()
props = (
    ('top', 'top_colour'), ('right', 'right_colour'),
    ('bottom', 'bottom_colour'), ('left', 'left_colour')
)
# Thiết lập kiểu dáng và màu viền cho 4 hướng thông qua vòng lặp
for position, color in props:
    # Sử dụng hàm tích hợp setattr để gán giá trị động cho thuộc tính của đối tượng
    setattr(borders, position, xlwt.Borders.DASHED)
    setattr(borders, color, 5)
header_style.borders = borders
```

Nếu muốn điều chỉnh độ rộng của ô (độ rộng cột) và chiều cao của tiêu đề (chiều cao hàng), bạn có thể thao tác theo đoạn code dưới đây:

```python
# Thiết lập chiều cao hàng là 40px
sheet.row(0).set_style(xlwt.easyxf(f'font:height {20 * 40}'))
titles = ('姓名', '语文', '数学', '英语')
for index, title in enumerate(titles):
    # Thiết lập độ rộng cột là 200px
    sheet.col(index).width = 20 * 200
    # Thiết lập dữ liệu và định dạng cho ô
    sheet.write(0, index, title, header_style)
```

### Tính toán bằng công thức

Đối với tệp "阿里巴巴2020年股票数据.xls" đã mở ở phần trước, nếu muốn thống kê giá trị trung bình của giá đóng cửa cả năm (trường Close) và tổng khối lượng giao dịch cả năm (trường Volume), chúng ta có thể sử dụng công thức tính toán của Excel. Chúng ta có thể dùng `xlrd` để đọc tệp Excel trước, sau đó dùng hàm `copy` do thư viện bên thứ ba `xlutils` cung cấp để chuyển tệp Excel đã đọc thành đối tượng `Workbook` để thực hiện thao tác ghi. Khi gọi phương thức `write`, ta có thể ghi một đối tượng `Formula` vào ô.

Đoạn code thực hiện tính toán bằng công thức như sau:

```python
import xlrd
import xlwt
from xlutils.copy import copy

wb_for_read = xlrd.open_workbook('阿里巴巴2020年股票数据.xls')
sheet1 = wb_for_read.sheet_by_index(0)
nrows, ncols = sheet1.nrows, sheet1.ncols
wb_for_write = copy(wb_for_read)
sheet2 = wb_for_write.get_sheet(0)
sheet2.write(nrows, 4, xlwt.Formula(f'average(E2:E{nrows})'))
sheet2.write(nrows, 6, xlwt.Formula(f'sum(G2:G{nrows})'))
wb_for_write.save('阿里巴巴2020年股票数据汇总.xls')
```

> **Giải thích**: Đoạn code trên có một chút khuyết điểm nhỏ, bạn đọc quan tâm có thể tự tìm tòi và suy nghĩ cách giải quyết.
