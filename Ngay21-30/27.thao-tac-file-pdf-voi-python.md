## Thao tác với file PDF bằng Python

PDF là viết tắt của Portable Document Format, loại file này thường sử dụng phần mở rộng `.pdf`. Trong công việc phát triển hàng ngày, hai tác vụ phổ biến nhất mà chúng ta hay gặp phải là trích xuất nội dung văn bản từ file PDF và tạo tài liệu PDF từ nội dung có sẵn.

### Trích xuất văn bản từ PDF

Trong Python, bạn có thể sử dụng thư viện bên thứ ba `PyPDF2` để đọc file PDF, có thể cài đặt bằng lệnh dưới đây:

```Bash
pip install PyPDF2
```

`PyPDF2` không thể trích xuất hình ảnh, biểu đồ hoặc các phương tiện khác từ tài liệu PDF, nhưng nó có thể trích xuất văn bản và trả về dưới dạng chuỗi (string) trong Python.

```python
import PyPDF2

reader = PyPDF2.PdfReader('test.pdf')
for page in reader.pages:
    print(page.extract_text())
```

Tất nhiên, `PyPDF2` không phải tài liệu PDF nào cũng có thể trích xuất được chữ; theo hiểu biết của tôi thì vấn đề này chưa có giải pháp nào thực sự hoàn hảo, đặc biệt là khi trích xuất chữ tiếng Trung. Trên mạng cũng có rất nhiều bài viết hướng dẫn trích xuất chữ từ PDF, khuyên bạn nên tự đọc bài viết [《三大神器助力Python提取pdf文档信息》](https://cloud.tencent.com/developer/article/1395339) để tìm hiểu thêm.

Nếu muốn trích xuất văn bản từ file PDF, bạn cũng có thể trực tiếp sử dụng công cụ dòng lệnh của bên thứ ba, cách làm cụ thể như sau:

```Bash

```

### Xoay và ghép chồng các trang

Trong đoạn mã trên, chúng ta đọc tài liệu PDF bằng cách tạo đối tượng `PdfFileReader` (hoặc `PdfReader`). Phương thức `getPage` của đối tượng này có thể lấy ra trang chỉ định của tài liệu PDF và trả về một đối tượng `PageObject`. Thông qua các phương thức `rotateClockwise` và `rotateCounterClockwise` (hoặc `rotate`) của đối tượng `PageObject`, chúng ta có thể xoay trang theo chiều kim đồng hồ hoặc ngược chiều kim đồng hồ; thông qua phương thức `addBlankPage` của `PageObject`, chúng ta có thể thêm một trang trắng mới, như đoạn mã dưới đây:

```python
reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for no, page in enumerate(reader.pages):
    if no % 2 == 0:
        new_page = page.rotate(-90)
    else:
        new_page = page.rotate(90)
    writer.add_page(new_page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Mã hóa file PDF

Sử dụng đối tượng `PdfFileWriter` (hoặc `PdfWriter`) trong `PyPDF2` có thể mã hóa tài liệu PDF. Nếu cần thiết lập mật khẩu truy cập đồng nhất cho một loạt tài liệu PDF, việc sử dụng chương trình Python để xử lý sẽ vô cùng tiện lợi.

```python
import PyPDF2

reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for page in reader.pages:
    writer.add_page(page)
    
writer.encrypt('foobared')

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Thêm hình mờ (watermark) hàng loạt

Đối tượng `PageObject` được nhắc đến ở trên còn có một phương thức mang tên `mergePage` (hoặc `merge_page`), có thể ghép chồng hai trang PDF lại với nhau. Qua thao tác này, chúng ta có thể dễ dàng thực hiện tính năng thêm hình mờ vào file PDF. Ví dụ, để thêm hình mờ vào file "XGBoost.pdf" ở trên, trước tiên chúng ta chuẩn bị một file PDF chứa trang hình mờ, sau đó đọc `PageObject` chứa hình mờ ra, rồi duyệt qua từng trang của file "XGBoost.pdf" để lấy đối tượng `PageObject`, sau đó dùng phương thức `merge_page` để hợp nhất trang hình mờ với trang gốc. Đoạn mã như sau:

```python
reader1 = PyPDF2.PdfReader('XGBoost.pdf')
reader2 = PyPDF2.PdfReader('watermark.pdf')
writer = PyPDF2.PdfWriter()
watermark_page = reader2.pages[0]

for page in reader1.pages:
    page.merge_page(watermark_page)
    writer.add_page(page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

Nếu muốn, bạn còn có thể để các trang lẻ và trang chẵn sử dụng các hình mờ khác nhau, mọi người có thể tự suy nghĩ xem nên làm thế nào nhé.

### Tạo file PDF

Để tạo tài liệu PDF, chúng ta cần sự hỗ trợ của thư viện bên thứ ba `reportlab`. Cách cài đặt như sau:

```Bash
pip install reportlab
```

Dưới đây là một ví dụ minh họa cách sử dụng `reportlab`:

```python
from reportlab.lib.pagesizes import A4
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.pdfgen import canvas

pdf_canvas = canvas.Canvas('resources/demo.pdf', pagesize=A4)
width, height = A4

# Vẽ hình
image = canvas.ImageReader('resources/guido.jpg')
pdf_canvas.drawImage(image, 20, height - 395, 250, 375)

# Hiển thị trang hiện tại
pdf_canvas.showPage()

# Đăng ký file phông chữ
pdfmetrics.registerFont(TTFont('Font1', 'resources/fonts/Vera.ttf'))
pdfmetrics.registerFont(TTFont('Font2', 'resources/fonts/青呱石头体.ttf'))

# Viết chữ
pdf_canvas.setFont('Font2', 40)
pdf_canvas.setFillColorRGB(0.9, 0.5, 0.3, 1)
pdf_canvas.drawString(width // 2 - 120, height // 2, 'Xin chào, thế giới!')
pdf_canvas.setFont('Font1', 40)
pdf_canvas.setFillColorRGB(0, 1, 0, 0.5)
pdf_canvas.rotate(18)
pdf_canvas.drawString(250, 250, 'hello, world!')

# Lưu lại
pdf_canvas.save()
```
